# AMEX Card Usage Analysis 

## Overview

This project uses SQL to analyze **card member transaction data** and identify spending patterns across card segments, categories, cities, and time periods.

The analysis focuses on **10 business problems**, covering spending concentration, category behavior, city-level performance, monthly trends, festive vs. non-festive spending, weekend behavior, high-value transactions, and Travel spending.

## SQL Concepts Used

* Aggregation (`SUM`, `COUNT`, `AVG`)
* `GROUP BY` and `ORDER BY`
* `CASE WHEN`
* CTEs
* Window Functions
* `RANK()`
* `LAG()`
* Conditional Aggregation
* Percentage Calculations

## Key Insights

* Metro cities account for **55.8% of total spend**.
* Very High-value transactions contribute **45% of total spend**.
* Travel spending is **4.2% higher during festive periods**.
* Travel spending is **7.5% higher on weekends**.
* Spending behavior suggests that **category and customer behavior provide useful signals beyond card tier**.

## Business Recommendations

The analysis suggests focusing on high-value customers, prioritizing Metro markets, timing Travel campaigns around weekends and festive periods, and using spending behavior for more relevant customer engagement.

## Disclaimer

This is an **independent portfolio project** using public/anonymized transaction data. It does not use official American Express organizational, internal, or proprietary data and is not an official American Express analysis.
